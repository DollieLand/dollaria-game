# Изображения кукол

Сюда нужно положить иллюстрации кукол. Пока файла нет, игра показывает аккуратную заглушку `placeholder.svg`.

Правила:
- имя файла = id куклы из `backend/src/data/dolls.js` + `.png` (можно `.webp`, тогда поменяйте расширение в `frontend/src/components/doll.js`);
- вертикальная картинка, пропорция 3:4, рекомендуемый размер 900×1200;
- фон можно оставить прозрачным или розовым.
